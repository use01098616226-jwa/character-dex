# 🧪 브라우저 자체 테스트 시나리오 및 검증 결과

본 문서는 바이브 코딩 과정에서 구현된 기능들이 요구사항에 맞게 정상 동작하는지 브라우저에서 직접 검증한 테스트 기록입니다.

## 1. 기능 검증 체크리스트

| 테스트 ID | 테스트 항목 | 검증 시나리오 | 결과 | 비고 |
| :---: | :--- | :--- | :---: | :--- |
| **TC-01** | 초기 렌더링 | `index.html` 실행 시 기본 캐릭터 3종과 첫 번째 캐릭터(하치와레)의 카드 4장이 정상 출력되는가? | **PASS** | 에러 없음 |
| **TC-02** | 다이내믹 테마 | 좌측 사이드바에서 캐릭터 클릭 시 상단 배너 정보와 테마 색상(파랑/분홍/노랑)이 즉시 변경되는가? | **PASS** | CSS 변수 연동 확인 |
| **TC-03** | 3D 카드 플립 | 카드를 클릭했을 때 180도 회전하며 뒷면 명대사가 보이고, 다시 클릭하면 앞면으로 돌아오는가? | **PASS** | `:hover`에서 클릭으로 수정 완료 |
| **TC-04** | 삭제 이벤트 분리 | 카드 우측 상단 `✕` 삭제 버튼 클릭 시 카드가 뒤집히지 않고 삭제 확인창만 정확히 호출되는가? | **PASS** | `stopPropagation()` 적용 |
| **TC-05** | 마지막 캐릭터 보호 | 등록된 캐릭터가 1명만 남았을 때 캐릭터 삭제 시도 시 경고창이 뜨며 삭제가 방지되는가? | **PASS** | 빈 도감 방지 처리 |
| **TC-06** | 복합 필터링 | `#먹방` 태그 선택 후 검색창에 `라면` 입력 시 조건에 부합하는 카드만 필터링되는가? | **PASS** | 태그 + 검색어 교집합 동작 |
| **TC-07** | 이미지 Fallback | 모습 카드 추가 시 이미지 URL에 잘못된 주소를 입력해도 깨진 아이콘 대신 내장 SVG 일러스트가 출력되는가? | **PASS** | `onerror` 핸들러 정상 작동 |
| **TC-08** | 영속성 및 초기화 | 새 캐릭터/카드 추가 후 브라우저 새로고침(F5) 시 데이터가 유지되며, 초기화 버튼 클릭 시 원상 복구되는가? | **PASS** | `localStorage` 동기화 확인 |
